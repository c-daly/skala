# Assembly figures

The active guide uses ten lower s1-*.svg illustrations generated by make_s1_figures.py and three upper u1-*.svg illustrations generated by make_upper_figures.py. Upper drawings show the actual plate sections and selected support holes, board layout/orientation, and fastener stacks/assembly order. Printed-part legends use exact names and filenames from cad/print_parts.json.

Run from the repository root:

    uv run docs/assembly/figures/make_s1_figures.py --preview-dir /tmp/skala-s1-assembly-figures
    uv run docs/assembly/figures/make_upper_figures.py --preview-dir /tmp/skala-upper-figures

The generator checks the retained source geometry, illustrated motor holes, idler slot, hub depth and connector clearances. Idler hub/cap section outlines come directly from the current CAD solids, including the rear collar, cap pilots and countersink. Bearings and the wheel plate are simplified and marked as such. Its source receipt is s1-figure-sources.json. Inspect every rendered PNG before refreshing the vault. SVGs have an explicit white background; the vault receives those SVGs, not separate image copies.

The upper receipt is u1-figure-sources.json. These are assembly schematics, not manufacturing templates or physical qualification. The raw CAD review projections do not explain assembly and are not embedded in the guide.

The U2 sensor guide adds three drawings generated by `make_sensor_figures.py`: existing-hole layout/stack height, captured camera pivot, and sensor fastening/cable allocations. Their part legends use `cad/sensor_parts.json`; `u2-figure-sources.json` pins the geometry and generator. Run `uv run docs/assembly/figures/make_sensor_figures.py --preview-dir /tmp/skala-sensor-figures` and inspect all three PNGs. Conditional HAT seating, A1 model and servo/horn matches remain explicit in the guide.

`u2-04-completed-assembly.svg` shows the whole robot after step 10, using current CAD in three-quarter and side views. Generate it with `uv run docs/assembly/figures/make_completed_sensor_view.py`. The standalone SVG embeds the rendered geometry and retains vector labels; its preview goes to `/tmp/skala-completed-assembly`. A source-hashed tessellation cache in `/tmp` avoids rebuilding unchanged CAD while revising labels. `u2-04-completed-assembly-sources.json` records source and output hashes. The view excludes proposed power hardware and identifies simplified equipment, omitted cable detail and the unfinished interface-board attachment. The A1 base webs illustrate its housing joining the modeled mounting feet; that shell outline is not fit or clearance geometry. Inspect the rendered image before syncing the vault.

Numbered figures and make_figures.py in this directory depict superseded assemblies. They are not used by the current guide and must not supply dimensions, wiring or print instructions for S1.
